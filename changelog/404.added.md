`TabPFNClassifier` and `TabPFNRegressor` gained `submit_fit()`, which starts a fit without waiting for it, and `wait_for_fit()`. `save_model()` saves the pending model, so a later run can `load_model()` it and wait for the same fit instead of fitting again; until the fit has been waited for, `predict()` raises `NotFittedError`. A fit the server reports as failed now raises `FitFailedError`, a `RuntimeError`.
