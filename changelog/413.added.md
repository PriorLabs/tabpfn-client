`TabPFNClassifier` and `TabPFNRegressor` gained `submit_predict()`, which starts a prediction as a background job without waiting for it, and `wait_for_predict()`, which waits for it and returns what `predict()` returns, or `predict_proba()` for `output_type="probas"`. `save_model()` saves the pending prediction, so a later run can `load_model()` and wait for the same prediction instead of predicting again. Two new errors, both `RuntimeError`s: `PredictFailedError`, raised when the client polls for a prediction and the server reports that it failed, and its subclass `RefitRequiredError`, raised when the fitted model can no longer predict: call `fit()` again.
