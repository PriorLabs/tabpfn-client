A thinking-mode fit now always runs as a background job that the client polls, whatever `api_mode` is, instead of keeping one request open for up to an hour. `fit()` still returns once the fit has completed, and in every mode waits for it for at most `TABPFN_CLIENT_ASYNC_POLL_TIMEOUT` seconds: by default the server's 2 hours, which outlasts the server's own deadline for a fit. If that wait stops, for a timeout or an interrupt, the model is pending on the new fit, which `wait_for_fit()` resumes and `save_model()` saves; a fit that the server reports as failed while `fit()` waits for it leaves the model unfitted.
