New `tabpfn_client.explain.permutation_shap()` computes SHAP values for many explained rows in each prediction request, not one request per row as `shap.PermutationExplainer` does. Pass the training data as `background`, and it samples `n_background` rows (20 by default). Requests are sized to the API limits. `to_shap()` gives a `shap.Explanation` for the shap plots.
