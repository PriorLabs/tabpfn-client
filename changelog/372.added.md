`tabpfn_client.hosted` estimators accept `use_kv_cache=True`, which reuses the endpoint's already-fitted model across repeated `predict` calls instead of re-fitting on every one — a large speed-up for workloads that predict many times against a single fit, such as SHAP, permutation importance and partial dependence. The endpoint's cache is bounded, so a model can be evicted between calls; that surfaces as an error and the estimator has to be re-fit.
