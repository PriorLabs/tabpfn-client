With `api_mode="auto"`, the default, `predict()` now runs a prediction as a background job, which the client polls, once the training rows of the fit or the rows to predict reach thresholds that the server sets; a fit with `fit_mode="fit_with_cache"` still predicts with one request. A prediction that takes longer than the server waits on one request no longer fails: the client polls for its result. A prediction that needs a new fit raises `RefitRequiredError` instead of a plain `RuntimeError`. A regressor's `"full"` output that is split over several requests keeps up to 4 of them running at once when they run as background jobs.
