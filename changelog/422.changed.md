A prediction that the server created and that then fails now raises `PredictFailedError`, or `RefitRequiredError` when the model must be fitted again, also when the server reports the failure in answer to the `predict()` request itself. Such a failure used to raise a generic `RuntimeError`, or for an HTTP 503 or 504 an internal retryable error. `submit_predict()` raises these errors too when the server reports the failure at once, and `PredictFailedError.fitted_test_set_id` holds the id of the prediction.
